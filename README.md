# Дом в порядке

Устанавливаемая PWA для iPhone, которая хранит график обслуживания домашней техники и напоминает о следующей чистке.

Приложение опубликовано по адресу: [vitkevich-ivan.github.io/homeCleanerReminder](https://vitkevich-ivan.github.io/homeCleanerReminder/).

## Возможности

- техника, периодичность и автоматический расчёт следующей чистки;
- полная история дат с добавлением и удалением записей;
- адаптивный интерфейс и офлайн-работа;
- облачная синхронизация через Supabase с отдельными данными каждого пользователя;
- регистрация, вход, восстановление пароля и управление email-аккаунтом;
- фоновые Web Push-напоминания с выбором часа и тестовой отправкой;
- установка на экран «Домой» и управляемое обновление PWA.

На iPhone откройте приложение в Safari, нажмите **Поделиться**, затем **На экран «Домой»**.

## Разработка

Клиент находится в `web` и не требует сборщика. Проверки запускаются командой:

```bash
npm ci
npm run check
```

GitHub Actions публикует содержимое `web` в GitHub Pages после push в `dev`.

## Supabase

Пошаговая настройка базы, авторизации, Edge Functions и push-секретов находится в [`supabase/SETUP.md`](supabase/SETUP.md). Настройка email — в [`supabase/EMAIL_AUTH.md`](supabase/EMAIL_AUTH.md).

Данные защищены Row Level Security. Секретные ключи не должны попадать в клиентский код или Git.

## Ветки и расписание

Рабочая версия находится в `dev`, а `main` сохранена как исходный первый коммит. Чтобы GitHub запускал workflow `Send Due Reminders` по расписанию, в **GitHub → Settings → Branches → Default branch** необходимо выбрать `dev`: scheduled workflows выполняются только из default branch.

## Нативный прототип

Первоначальный SwiftUI-прототип и Xcode-проект сохранены в репозитории как архив разработки. Актуальная устанавливаемая версия — PWA из каталога `web`.
