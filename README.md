# HomeCleaner

Нативное приложение для iPhone, которое хранит график обслуживания домашней техники и напоминает о следующей чистке.

## Возможности MVP

- добавление и редактирование техники;
- периодичность и дата последней чистки;
- автоматический расчёт следующей даты;
- статусы «просрочено», «скоро» и «позже»;
- локальные уведомления;
- отметка «Очищено сегодня» и история чисток;
- локальное хранение через SwiftData.

## Требования

- iOS 17 или новее;
- Xcode 15 или новее;
- macOS для сборки и запуска iOS Simulator.

## Запуск

1. Откройте `HomeCleaner.xcodeproj` в Xcode.
2. Выберите симулятор iPhone с iOS 17 или новее.
3. Нажмите Run (`⌘R`).

Для установки на физический iPhone выберите свою Apple Developer Team в разделе Signing & Capabilities и уникальный Bundle Identifier.

## Автоматическая сборка

GitHub Actions запускает сборку после каждого push или pull request в `main`. Артефакт `HomeCleaner-iOS17` можно скачать на странице завершённого workflow в разделе **Artifacts**. В скачанном архиве находится файл `HomeCleaner.ipa`.

Собранный IPA не подписан. Для установки на физический iPhone его нужно подписать своим Apple ID, например через Sideloadly. При использовании бесплатного Apple ID подпись обычно требуется обновлять каждые 7 дней.

## PWA-версия

В каталоге `web` находится устанавливаемая веб-версия приложения. Она поддерживает:

- добавление и редактирование техники;
- расчёт следующей чистки и статусы просрочки;
- историю выполненных чисток;
- локальное хранение данных без регистрации;
- офлайн-работу после первого открытия;
- установку на экран «Домой» на iPhone.

GitHub Actions автоматически публикует PWA через GitHub Pages после изменений в каталоге `web`. Адрес приложения: [vitkevich-ivan.github.io/homeCleanerReminder](https://vitkevich-ivan.github.io/homeCleanerReminder/).

На iPhone откройте адрес в Safari, нажмите **Поделиться**, затем **На экран «Домой»**. Статическая PWA проверяет просроченные задачи при открытии. Для доставки фоновых push-уведомлений в закрытое приложение потребуется отдельный push-сервис.

### Supabase

PWA подключена к проекту Supabase для резервного хранения данных. При доступном облаке существующие локальные записи автоматически синхронизируются, а при недоступном — приложение продолжает работать офлайн.

Перед включением синхронизации необходимо один раз применить SQL-миграцию и включить Anonymous Sign-Ins. Пошаговая инструкция находится в [`supabase/SETUP.md`](supabase/SETUP.md). Таблицы защищены Row Level Security: каждая сессия имеет доступ только к собственным данным.

Фоновые Web Push-уведомления реализованы через Supabase Edge Function. После настройки VAPID-секретов GitHub Actions проверяет наступившие даты каждый час и отправляет уведомление установленной PWA в 10:00 по локальному времени пользователя.
