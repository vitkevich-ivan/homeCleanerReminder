# HomeCleaner

Нативное приложение для iPhone, которое хранит график обслуживания домашней техники и напоминает о следующей чистке.

## Возможности MVP

- добавление и редактирование техники;
- периодичность и дата последней чистки;
- автоматический расчёт следующей даты;
- статусы «просрочено», «скоро» и «позже»;
- локальные уведомления;
- отметка «Очищено сегодня» и история чисток;
- локальное хранение через SwiftData.

## Требования

- iOS 17 или новее;
- Xcode 15 или новее;
- macOS для сборки и запуска iOS Simulator.

## Запуск

1. Откройте `HomeCleaner.xcodeproj` в Xcode.
2. Выберите симулятор iPhone с iOS 17 или новее.
3. Нажмите Run (`⌘R`).

Для установки на физический iPhone выберите свою Apple Developer Team в разделе Signing & Capabilities и уникальный Bundle Identifier.

## Автоматическая сборка

GitHub Actions запускает сборку после каждого push или pull request в `main`. Готовый архив `HomeCleaner-Simulator.zip` можно скачать на странице завершённого workflow в разделе **Artifacts**.

Артефакт предназначен для iOS Simulator. Для установки приложения на физический iPhone потребуется настроить Apple Developer Team, сертификат и provisioning profile в GitHub Secrets.
