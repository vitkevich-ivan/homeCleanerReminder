Конфиденциальность

«Дом в порядке» хранит названия техники, даты чисток, настройки напоминаний и, при регистрации, адрес электронной почты.

Данные используются только для синхронизации между устройствами и отправки выбранных пользователем напоминаний. Пароли обрабатываются Supabase Auth и не сохраняются в коде приложения.

Доступ к данным защищён правилами Row Level Security: пользователь видит только собственные записи. Push-подписку можно отключить в настройках напоминаний.

Удалить аккаунт и связанные облачные данные можно в экране аккаунта внутри приложения. Вопросы можно оставить в разделе Issues репозитория проекта.
