# Email-аутентификация HomeCleaner

Текущий анонимный пользователь преобразуется в постоянный email-аккаунт через `updateUser({ email, password })`. Его `user_id`, техника, история и push-подписка сохраняются. На другом устройстве используется `signInWithPassword`.

## Настройка Supabase

1. Откройте **Authentication → Providers → Email** и убедитесь, что Email provider включён.
2. Рекомендуется оставить **Confirm email** включённым.
3. Откройте **Authentication → URL Configuration** и задайте:
   - Site URL: `https://vitkevich-ivan.github.io/homeCleanerReminder/`;
   - Redirect URL: `https://vitkevich-ivan.github.io/homeCleanerReminder/`.
4. При необходимости отредактируйте письмо **Confirm signup** в разделе Email Templates.

## Использование

1. Нажмите индикатор облака в правом верхнем углу PWA.
2. Введите email и пароль длиной не менее 8 символов.
3. Нажмите **Создать аккаунт** и подтвердите адрес по ссылке из письма.
4. Если ссылка открылась в Safari, вернитесь в установленную PWA, снова введите пароль и нажмите **У меня уже есть аккаунт**.
5. На другом устройстве установите PWA, откройте экран аккаунта, введите те же данные и нажмите **У меня уже есть аккаунт**.

Пароли обрабатывает Supabase Auth. Они не сохраняются в локальных данных приложения или репозитории.

## Если ссылка ведёт на localhost или устарела

`http://localhost:3000` означает, что в **Authentication → URL Configuration** остался стандартный Site URL или production-адрес не добавлен в Redirect URLs. Замените его на адрес GitHub Pages выше, сохраните настройки, затем в PWA нажмите **Отправить письмо повторно**. Старая одноразовая ссылка с ошибкой `otp_expired` больше не действительна.
